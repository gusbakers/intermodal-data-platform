# Reproducible analysis outputs

These files are generated by `python run_full_pipeline.py` from the included source CSV:

- `metrics.json`: exact snapshot KPIs.
- `data_quality_report.json`: checked and failed row counts for every implemented rule.
- `tables/`: dashboard, mode, route, cargo, priority and fuel KPI tables.
- `figures/`: four PNG figures used in the README and executive notebook.

`run_summary.json` is generated locally and ignored by Git. It contains the source checksum, completion timestamp, actual elapsed time and explicit database status for that run. GitHub Actions uploads regenerated outputs as workflow artifacts.

Saved notebook outputs and these tables describe the provided shipment snapshot. They do not establish source authenticity, causal effects or realized business savings.
